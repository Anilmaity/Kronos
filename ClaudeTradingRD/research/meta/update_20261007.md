## 2. Method

Same machinery as the 2026-09-23 campaign, unchanged: `concept_lab` (`concept_lab-rules-2`,
locked), symmetric look-ahead probe, matched controls, two adversarial verifiers per raw EDGE
(implementation lens + faithfulness lens), Holm/BH over every hypothesis ever run including
unwritten ones. Orchestrated as one workflow (`wf_f4925912-841`, 87 Opus agents):
20 study agents in parallel → dedupe by concept id → one tester per concept → verifiers.

**Vault-preloaded re-audit.** The first 31 tests ran without the project vault in context. On the
operator's instruction they were re-run as audits with the vault preloaded. **18 of 31 had a real
flaw**, fixed under the same reading label (same hypothesis, no extra multiplicity):

| flaw | concepts |
|---|---|
| null/control not matched on NY time of day (README trap 9; campaign lesson 3) | consolidation, gold-daily-gap-reaction, hourly-cisd-confirmation, large-wick-target-adjustment, smt-divergence, inside-day-three-levels (also not vol-matched), partial-profit-taking, protected-swing (null manufactured the sign) |
| stale/incomplete event calendars | fomc-nfp-cpi-only (BLS January NFP deferral), no-bias-reaction-day (FOMC list ended 2026-03-18) |
| test did not match the source | fractal-model-c2 (scored C2's own extreme from C3), tgif-setup (weekly objective omitted), stop-loss-placement (2R floor not applied), invalidation-trade (close *through* EQ not enforced) |
| provenance / bookkeeping | prop-firm-drawdown-sizing (non-verbatim quote), exit-when-target-nearly-hit (result ledgered but never written), continuation-over-reversal (rules text described the tie-break backwards), consolidation-range-no-trade (claimed an M1-only data limit; H1 correlates exist) |

Lesson for future campaigns: **testers must start from the vault**, above all the time-of-day
matching rule. It is now a standing instruction (operator memory `subagents-opus-vault-preload`).
